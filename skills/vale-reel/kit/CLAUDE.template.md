# Video project notes

- House style: `STYLE.md` (source of truth) and `brand/BRAND.md` + `brand/tokens.json`. Read them before adding captions, titles, cards, a grade, sound or any on-screen text.
- Pipeline: follow the `vale-reel` skill (transcribe → cut → approval → storyboard → approval → render → Premiere). Never render before the storyboard is approved.
- Fonts: Helvetica Neue (system), Caveat, Newsreader, Hanken Grotesk, DM Mono (in `brand/fonts/`; check they're installed before using them in Premiere).
- Graphics placement on tight talking-head framing: titles in the top band (y ~70-300), captions and lower thirds in the bottom band (y ~1470), never together.
- Sounds: no library by default; the synthesised set lives in `style-lab/round*/gen*.py`. See `SOUND-LIBRARY.md`.
