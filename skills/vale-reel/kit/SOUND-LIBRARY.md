# Sound library

There's no sound effects library on this Mac (checked 2026-10-17), so `sound-library.json` is empty.

When a round needs a sound, it's made with an AI sound effects generator that you have access to, then trimmed, given short fades and kept under -1 dB peak. Generated sounds are saved under `style-lab/sounds/` with the prompt that made them.

If you add a library later, give me the folder and I'll index it here, grouped as clicks and UI, whooshes, hits and impacts, risers, glitches, foley, ambience, and other.
